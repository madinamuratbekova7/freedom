# «Засада» — тренажёр самостоятельных решений

Прототип для Women's Hack Day 2026, трек Product Design, кейс 2 «От правильного ответа к самостоятельному решению».

Клиент сначала отговаривает новичка вкладывать всё в одну акцию — своими словами, без вариантов ответа. Через несколько дней в ленте появляется похожая ситуация без пометки «урок». Последствия решения показываются в 2000 смоделированных вариантах будущего.

Все компании, суммы и параметры рынка вымышлены.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Открыть http://localhost:5173. Тесты движка: `npm test`.

## Как показать за 40 секунд

1. Шаг «Спор»: написать «эээ» — Айгерим переспросит (случай непонимания). Затем «Не стоит, компания может рухнуть» — она возразит про рост.
2. Шаг «Засада» (кнопка вверху): передвинуть первый ползунок на 100% → «Подтвердить решение».
3. «Перемотка»: переключить вкладку на «Тот же миллион, разложенный».
4. «Открыть чёрный ящик» — разбор ошибки.
5. Вкладка «Эксперимент» вверху справа: три способа измерить один эффект. Подвигать «Рынок» — оценка «до и после» уезжает, A/B остаётся на месте.
