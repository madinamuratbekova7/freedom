## Слайд 6. План проверки (2:15–2:35)

- **Схема:** новички → случайное деление → [Контроль: урок + тест] / [Тест: «Засада»] → сравнение на D30
- **Три подписи к схеме:**
  - Случайность + стратификация по стажу → уравниваем опыт и мотивацию
  - Один календарный период → рынок одинаков
  - Считаем всех начавших, а не закончивших → нет отбора мотивированных
- **Внизу:** «≈ 1070 клиентов на группу (40% → 46%, α = 0,05, мощность 80%)»
- **До запуска:** 5–8 коридорных тестов прототипа
