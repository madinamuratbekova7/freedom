# Как выложить «Засаду» на Netlify

Есть два способа. **Способ 1** — подключить репозиторий: сайт будет сам обновляться после каждого пуша. **Способ 2** — перетащить папку: занимает минуту и не требует доступа к GitHub, но обновлять придётся вручную.

Настройки сборки уже лежат в `netlify.toml` в корне репозитория, вводить их руками не нужно.

Названия кнопок в Netlify иногда меняются — ориентируйтесь по смыслу.

---

## Способ 1. Подключить репозиторий (автообновление)

**Кто делает:** владелица репозитория — Мадина (`madinamuratbekova7`). Netlify нужно разрешение на доступ к репозиторию, а выдать его может только владелец аккаунта, где репозиторий лежит.

1. Открыть https://app.netlify.com и нажать **Sign up** → **GitHub**. Войти под аккаунтом `madinamuratbekova7`.
2. На главной нажать **Add new site** (или **Add new project**) → **Import an existing project**.
3. Выбрать **GitHub**. Откроется окно GitHub — нажать **Authorize Netlify**.
4. В окне установки выбрать **Only select repositories** → `freedom` → **Install**.
5. В списке репозиториев выбрать `freedom`.
6. Проверить, что поля заполнились сами:
   - Branch to deploy: `main`
   - Build command: `npm run build`
   - Publish directory: `dist`
7. Нажать **Deploy freedom**. Сборка идёт около минуты.
8. Когда статус станет **Published**, вверху появится ссылка вида `https://что-то-случайное.netlify.app` — это и есть сайт.

**Поменять адрес на понятный:** Site configuration → **Change site name** → например, `zasada-whd` → сайт будет на `https://zasada-whd.netlify.app`.

**Дальше всё само:** каждый `git push` в `main` запускает новую сборку, через минуту сайт обновлён.

## Способ 2. Перетащить папку (без доступа к GitHub)

**Кто делает:** любой участник команды, у кого проект запускается на компьютере.

1. Скачать свежую версию и собрать:

```bash
git pull
```

```bash
npm install
```

```bash
npm run build
```

2. В папке проекта появится папка `dist` — это готовый сайт.
3. Открыть https://app.netlify.com/drop (нужно войти в любой аккаунт Netlify).
4. Перетащить папку `dist` целиком в окно браузера.
5. Через несколько секунд появится ссылка `https://что-то-случайное.netlify.app`.

**Чтобы обновить сайт:** снова выполнить `npm run build`, открыть сайт в Netlify → вкладка **Deploys** → перетащить новую папку `dist` в область внизу страницы.

## Проверка после деплоя

Открыть ссылку и пройти сценарий:

1. Поставить галочку согласия → **Начать спор**.
2. Написать «эээ» — Айгерим должна переспросить.
3. Вверху нажать шаг **Засада**, передвинуть первый ползунок на 100% → **Подтвердить решение**.
4. Должен появиться график с траекториями и заголовок «В … из 2000 осталось меньше половины».

Открыть ссылку ещё и с телефона — жюри, скорее всего, будет смотреть так.

## Если что-то пошло не так

| Что видно | Что делать |
|---|---|
| В списке Netlify нет репозитория `freedom` | Шаг 4 пропущен или вошли не под тем аккаунтом GitHub. GitHub → Settings → Applications → Netlify → Configure → добавить `freedom` |
| Сборка упала с ошибкой (красный статус **Failed**) | Открыть лог деплоя, скопировать последние 20 строк и прислать в чат команды. Пока чинится — выложить способом 2 |
| Сайт открылся, но страница белая | Проверить, что Publish directory — `dist`, а не корень репозитория |
| Нужно срочно, а доступа к аккаунту Мадины нет | Способ 2: он не требует ничего, кроме собранной папки `dist` |
